Place app icons in this folder.

Expected file names:
- calmnow.png
- betterthanbetter.png
- gentlesteps.png
- wisdomroot.png
- fixit.png
- temporun.png

These files are served at /images/apps/<filename>.
Example: /images/apps/calmnow.png

Use square PNG files for best results.

Screenshot convention:
- Put app screenshots in this same folder.
- Use names like stickembowfishingpro-1.png, stickembowfishingpro-2.png, gentlesteps-1.png.
- Reference them in constants.ts through each app's screenshotPaths array.
- Tall mobile screenshots work best.
